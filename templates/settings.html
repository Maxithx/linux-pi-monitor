First-time SSH setup

First connect with your Linux account password. After that, switch the saved profile over to SSH key login:

  1. Enter the Linux host, username, and select Password.
  2. Enter the Linux account password, then click Save profile and Test.
  3. When the connection is working, change Authentication Method to SSH Key.
  4. If a valid key already exists, keep it. Otherwise click Generate key or Replace invalid key.
  5. Click Install key on host and enter the Linux password one last time. Only after that should the profile be saved as SSH Key.

Note: This is the password for the Linux account—not a Windows PIN. The password is only used to establish access and install the public key.
